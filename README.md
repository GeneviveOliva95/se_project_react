# WTWR

The WTWR ("What to Wear") is a weather-based clothing recommendation app filtered by weather conditions at the user's current location.

The goal of WTWR is to simplify the process of wardrobe personalization by integrating weather information, user-specific location, and style preferences.

The front-end utilizes React principles (components, props, state) and pulls live weather data from OpenWeatherMap API.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- React.js

## Tools

- OpenWeatherMap API
- Node Package Manager
- Git
- Figma

## Key Features

- Interactive clothing catalog
- Weather-based recommendations
- Location-based weather information

## Future Project Improvements

I aim to improve this project by implementing dynamic location search, user profile customization (avatar, username, etc.), and utilize adaptive design principles for dynamic screen resolutions.
